# NOVA AI — المزايا الجديدة وطريقة الإعداد

## المزايا المضافة
- بريد التواصل والدعم: karim071984@gmail.com، ويفتح تطبيق البريد عند الضغط عليه.
- نافذة «كيفية الاستخدام» من زر المساعدة أو أسفل الصفحة.
- إرفاق الصور من شاشة البداية أو داخل المحادثة.
- معاينة الصورة وحذفها قبل الإرسال.
- دعم PNG وJPG وWEBP وGIF حتى 5 ميغابايت.
- إرسال الصورة إلى محرك الذكاء الاصطناعي لتحليلها، مع التحقق من نوعها وحجمها على الخادم.
- إنشاء صور جديدة من الوصف داخل Image Studio مع رابط لحفظ الصورة.

## كيفية الاستخدام
1. اختر الأداة المناسبة من القائمة.
2. اكتب طلبك بوضوح، ثم اضغط زر الإرسال أو Enter.
3. لإرسال صورة اضغط رمز المشبك، واختر صورة، ثم اكتب ما تريد معرفته عنها.
4. لإنشاء صورة جديدة افتح Image Studio، اكتب وصف الصورة، ثم أرسل الطلب واحفظ النتيجة.
5. اضغط «New conversation» لبدء محادثة جديدة.
6. للتواصل اضغط «Contact support» أو بريد الدعم في نافذة المساعدة.

## تفعيل الذكاء الاصطناعي
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env.local`.
4. أضف مفتاح API في `OPENAI_API_KEY` على الخادم فقط.
5. شغّل `npm run dev` للاختبار، أو `npm run build` للبناء.

**ملاحظة:** إنشاء الصور يحتاج صلاحية استخدام نموذج `gpt-image-1` وقد يترتب عليه استهلاك مدفوع حسب حساب مزود الخدمة.

هذا ملف مصدر محسّن وليس APK جاهزاً. يلزم تثبيت المكتبات، إعداد مفتاح API، نشر الموقع واختبار البناء قبل إنتاج APK.


## حالة نسخة أندرويد
هذا الأرشيف مصدر موقع ويب/PWA وليس APK جاهزاً. يلزم أولاً تثبيت المكتبات على حاسوب متصل بالإنترنت، إضافة `OPENAI_API_KEY` في إعدادات الخادم فقط، ثم بناء ونشر مشروع Next.js. بعد نشره برابط HTTPS يمكن تثبيته من Chrome عبر «إضافة إلى الشاشة الرئيسية». إذا كنت تحتاج ملف APK أصلياً، يمكن تغليف الموقع المنشور باستخدام Capacitor وبناؤه عبر Android Studio وAndroid SDK. لا تضع مفتاح API داخل التطبيق.

## حالة تجهيز أندرويد
أضيفت أيقونات Android وملف PWA manifest. راجع `ANDROID_BUILD_GUIDE_AR.md` لمعرفة خطوات التشغيل والنشر والتثبيت. لم يكتمل بناء APK هنا لأن تنزيل حزم npm لم ينتهِ ضمن المهلة المتاحة، كما أن Android SDK وGradle غير مثبتين في بيئة البناء الحالية.
