# ابدأ من هنا — NOVA AI

## ما الذي يحتويه هذا المشروع؟
- موقع ويب متجاوب مبني بـ Next.js.
- واجهة دردشة وأدوات كتابة وترجمة وأفكار ومساعد أعمال.
- صفحات: من نحن، اتصل بنا، الخصوصية، شروط الاستخدام، كيفية الاستخدام، والخطط.
- مسار API للدردشة يعمل عبر مفتاح API محفوظ في الخادم.
- ملف PWA للتثبيت من المتصفح على الهاتف.

## مهم قبل النشر
هذه نسخة تأسيسية وليست خدمة تجارية مكتملة. لا يوجد حالياً تسجيل حسابات أو قاعدة بيانات أو دفع اشتراكات أو إنشاء صور حقيقي أو تكامل AdMob أو مشروع Android أصلي. صفحة الخطط تعريفية فقط. لا تكتب أن هذه المميزات مفعلة قبل تنفيذها واختبارها.

## نشر الموقع عبر Vercel
1. ارفع **محتويات المجلد** إلى مستودع GitHub، وليس ملف ZIP وحده.
2. افتح Vercel واختر Add New ثم Project ثم Import Git Repository.
3. اختر مستودع `nova-ai`.
4. اترك Framework على Next.js، وRoot Directory على `./`، والفرع الرئيسي `main`.
5. قبل النشر، أضف متغير البيئة `OPENAI_API_KEY` في إعدادات المشروع. لا تضع المفتاح في كود الواجهة أو في GitHub.
6. أضف `OPENAI_MODEL` بقيمة `gpt-4o-mini` إذا رغبت في تحديد النموذج.
7. اضغط Deploy. إذا فشل النشر، افتح Build Logs وانسخ رسالة الخطأ كاملة للمساعدة.

## تفعيل الدردشة
- أنشئ مفتاح API لدى مزود الذكاء الاصطناعي من حساب يملكه ولي أمرك/المسؤول البالغ عن المشروع.
- أضف المفتاح في Vercel ضمن Settings ثم Environment Variables باسم `OPENAI_API_KEY`.
- أعد Deploy بعد حفظ المتغير.
- لا ترسل المفتاح في المحادثة ولا تضعه في ملفات عامة.

## تحويله إلى تطبيق Android
هذا المشروع موقع Next.js مع PWA، وليس APK أو AAB. يحتاج تطبيق Android أصلياً أو غلافاً مدعوماً ومختبراً، ثم إعداد التوقيع وملف AAB. AdMob يحتاج SDK وإعدادات وموافقة خصوصية في تطبيق Android؛ وهو غير مدمج في هذه النسخة.
